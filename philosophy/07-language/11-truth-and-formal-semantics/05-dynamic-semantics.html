Dynamic Semantics

Static semantics maps a sentence and circumstance to a truth value. Discourse also changes the information against which later sentences are interpreted. Indefinites introduce referents, pronouns retrieve them, presuppositions impose background requirements, and assertions narrow possibilities.

Dynamic semantics models meaning as context change:

[[s]]:C↦C′.

Truth conditions can be recovered from update behaviour, but they are no longer the only semantic output.

Information states

Let C be a set of worlds compatible with current information. Updating with p:

C[p]={w∈C:p is true at w}.

Contradictory update yields the empty set. Tautological update leaves C unchanged.

Entailment can be represented through update:

p⊨qiffC[p][q]=C[p]

for every suitable C.

Discourse referents

Consider:

A student entered. She sat down.

A static existential appears to end with the first sentence. Dynamic representation introduces a discourse referent accessible to the pronoun.

Discourse representation structures or file-change semantics track:

  • variables introduced;
  • conditions imposed;
  • accessibility across embeddings.

This explains cross-sentence anaphora compositionally.

Donkey sentences

Every farmer who owns a donkey feeds it.

"A donkey" occurs inside a relative clause, yet "it" depends on it outside the indefinite's apparent scope.

Dynamic semantics lets the indefinite introduce a variable accessible under the quantificational structure. Competing analyses use unselective binding, choice functions, or E-type descriptions.

The case demonstrates why discourse dependency cannot always be represented by surface scope.

Presupposition

A presupposition can be an input requirement:

[[s]](C) is defined only if C supports p.

If p is not supported, interpreters may accommodate it by adjusting C before update.

Projection and filtering follow from how local and global contexts are constructed.

Questions

Questions update context by raising an issue rather than eliminating worlds directly. In inquisitive semantics, a content can encode alternatives whose resolution would answer the question.

This unifies information and inquiry:

  • assertions provide information;
  • questions request resolution;
  • disjunction can carry alternatives.

Conditionals

Dynamic conditionals update a temporary context with the antecedent, then test or update with the consequent:

C[if p, q]

depends on C[p]. This naturally explains presupposition filtering:

If Ada owns a bicycle, she regrets that her bicycle is outside.

The antecedent supplies what the consequent requires.

Context versus common ground

A formal information state is an abstraction. Real conversational context also tracks:

  • speaker commitments;
  • salience;
  • QUDs;
  • plans;
  • authority;
  • social knowledge.

Dynamic semantics can enrich state structure, but not every pragmatic factor should be encoded without independent motivation.

Truth conditions

Dynamic and static semantics can sometimes be translated:

[[p]]static={w:{w}[p]=∅}.

Dynamic equivalence may distinguish expressions with the same final truth conditions but different update potential.

The framework therefore refines rather than necessarily rejects truth-conditional semantics.

Assessment

Dynamic semantics is strongest for:

  • anaphora;
  • discourse reference;
  • presupposition projection;
  • conditionals;
  • questions;
  • information growth.

Its risk is overloading context with every interpretive fact. A useful dynamic theory specifies state components, update operations, and empirical predictions rather than using "context change" as a metaphor.
